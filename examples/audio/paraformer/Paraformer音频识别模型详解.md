## 1. 整体流程概览

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              输入: audio.wav                                │
│                              16kHz, 原始波形                                 │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 1: 分块 (Chunking) - 按 600ms 分块, 50% overlap                       │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │

┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 2: Fbank 特征提取 - 80维 Mel-filterbank, 25ms帧, 10ms帧移             │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 3: 编码器 (Encoder) - Conformer Encoder → 上下文相关的声学表示         │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 4: CIF Predictor - 变长序列 → 变长序列 (决定输出多少个 token)          │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 5: 解码器 (Decoder) - 自回归生成 token 序列                           │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  Step 6: 后处理 (Post-processing) - Token ID → 文字                        │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
                              输出: "你好世界"
```

## 2. 音频分块 (Chunking)

### 2.1 分块策略

```python
chunk_size = [0, 10, 5]  # [左边lookback, chunk长度(帧), 右边overlap(帧)]
chunk_stride = chunk_size[1] * 960  # 600ms @ 16kHz = 9600采样点
```

- `chunk_size[0] = 0`: 左边不需要回看
- `chunk_size[1] = 10`: 每个chunk 10帧 (600ms)
- `chunk_size[2] = 5`: 5帧 overlap (300ms)

### 2.2 图示

```
音频波形 (假设 2.5秒 = 40000采样点):
|───────────────────────────────────────────────────────|

分块 (600ms/块, stride=600ms):
Chunk 0: |████████████|                      (0-600ms)
Chunk 1:           |████████████|              (600-1200ms)
Chunk 2:                     |████████████|  (1200-1800ms)
Chunk 3:                               |████| (1800-2500ms, 最后一块)

overlap 用于 lookback, 让编码器能看到前后的上下文
```

### 2.3 不能整除时的处理

```python
total_chunk_num = int(len(speech - 1) / chunk_stride + 1)

for i in range(total_chunk_num):
    speech_chunk = speech[i * chunk_stride : (i + 1) * chunk_stride]
    is_final = (i == total_chunk_num - 1)
```

最后一个小于 960 采样点的 chunk 会被标记为 `is_final=True`，触发特殊的"收尾"处理。

## 3. Fbank 特征提取

### 3.1 处理流程

```
原始音频 → 预加重 → 分帧 → 加窗 → FFT → Mel滤波器 → 对数 → Fbank
```

### 3.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `fs` | 16000 | 采样率 |
| `frame_length` | 25ms | 每帧 25ms = 400 采样点 |
| `frame_shift` | 10ms | 帧移 10ms = 160 采样点 |
| `n_mels` | 80 | 80 个 Mel 滤波器 |

### 3.3 详细步骤

1. **预加重 (Pre-emphasis)**: 提升高频分量，补偿口唇辐射效应
2. **分帧 (Framing)**: 将音频分成 25ms 的小帧
3. **加窗 (Windowing)**: 使用 Hamming 窗口减少频谱泄漏
4. **FFT**: 将时域信号转换为频域
5. **Mel滤波器组**: 通过 80 个 Mel 尺度的三角滤波器提取频谱特征
6. **对数运算**: 取对数，模拟人耳对声音强度的对数感知

### 3.4 图示

```
原始音频 (600ms = 9600 采样点):
┌────────────────────────────────────────┐
│ ▁▂▃▄▅▆▇█▇▆▅▄▃▂▁▂▃▄▅▆▇█▇▆▅▄▃▂▁...      │
└────────────────────────────────────────┘

分帧 (25ms帧, 10ms移):
┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐
│ 0  │   │ 1  │   │ 2  │   │ 3  │   │ 4  │  ...
└───┘   └───┘   └───┘   └───┘   └───┘
  ↑       ↑       ↑       ↑
帧移   每帧提取 80 维 Mel 特征

最终: 600ms / 10ms = 60 帧, 每帧 80 维
      → (60, 80) 的 Fbank 特征矩阵
```

## 5. CIF Predictor

### 5.1 核心概念

CIF (Continuous Integration Focus) 是一种**连续积分聚焦**机制，将变长的频谱特征转换为变长的 token 序列。

### 5.2 工作原理

```
编码器输出 enc (60帧, 512维):
┌────────────────────────────────────────────────┐
│ h0, h1, h2, h3, h4, h5, ..., h59  (60个hidden) │
└────────────────────────────────────────────────┘
                    ↓ CIF Predictor
                    ↓ (预测每帧的 alpha 值)
                    ↓
alphas:        [0.3, 0.4, 0.5, 0.2, 0.6, ...]  (60个alpha)
                ↑                             ↑
             累积 < 1                      累积 >= 1
               continue                     → 输出 token!
```

### 5.3 积分过程

```python
for t in range(len_time):
    alpha = alphas[b][t]

    if alpha + integrate < self.threshold:  # 还没达到阈值
        integrate += alpha
        frames += alpha * hidden[b][t]      # 加权累积

    else:                                    # 达到或超过阈值 → 输出 token!
        frames += (self.threshold - integrate) * hidden[b][t]
        list_frame.append(frames)           # 输出一个 token
        integrate += alpha
        integrate -= self.threshold        # 剩余的继续累积
        frames = integrate * hidden[b][t]
```

**示例**:
```
假设 threshold = 1.0

t=0: alpha=0.3, integrate=0.0
     0.3 < 1.0 → 继续累积
     integrate=0.3, frames = 0.3 * h0

t=1: alpha=0.4, integrate=0.3
     0.4+0.3=0.7 < 1.0 → 继续累积
     integrate=0.7, frames = 0.3*h0 + 0.4*h1

t=2: alpha=0.5, integrate=0.7
     0.5+0.7=1.2 >= 1.0 → 触发输出! 🎉
     frames += (1.0-0.7)*h2 = 0.3*h2
     输出 token0 = frames (加权平均后的特征)

     integrate = 1.2 - 1.0 = 0.2
     frames = 0.2 * h2  (剩余的)
```

### 5.4 四个输出

| 输出 | 形状 | 含义 |
|------|------|------|
| **pre_acoustic_embeds** | `(B, T', D)` | CIF 积分后的声学嵌入，每个代表一个 token |
| **pre_token_length** | `(B,)` | 预测的 token 数量 |
| **alphas** | `(B, T)` | 每帧的累积系数 |
| **pre_peak_index** | `(B, T')` | 每帧的峰值位置索引 |

## 6. 解码器 (Decoder)

### 6.1 自回归生成

```python
decoder_out, _ = self.decoder(
    encoder_out=enc,                  # (T, D)
    encoder_out_lens=enc_len,         # T
    pre_acoustic_embeds=acoustic_embeds,  # (N, D)
    pre_token_length=token_length,    # N
)
```

### 6.2 生成过程图示

```
Step 0:
  输入: <sos> (start of sequence)
  Cross-Attend to enc → 预测下一个 token

Step 1:
  输入: <sos> 你
  Cross-Attend to enc → 预测下一个 token

Step 2:
  输入: <sos> 你 好
  Cross-Attend to enc → 预测下一个 token

... 直到预测出 <eos> (end of sequence)
```

### 6.3 Attention 机制

```
┌─────────────────────────────────────────────────────────────┐
│  Decoder Self-Attention:                                    │
│                                                             │
│    <sos> attends to <sos>                                  │
│    你    attends to <sos> 你                               │
│    好    attends to <sos> 你 好                            │
│    ...                                                     │
│                                                             │
│  Decoder Cross-Attention:                                   │
│                                                             │
│    <sos> attends to enc (音频的哪些帧对应"开头")            │
│    你    attends to enc (音频中对应"你"的那些帧)            │
│    好    attends to enc (音频中对应"好"的那些帧)           │
└─────────────────────────────────────────────────────────────┘
```

## 7. 后处理 (Post-processing)

### 7.1 Beam Search vs Greedy

```python
if self.beam_search is not None:
    # === Beam Search (集束搜索) ===
    nbest_hyps = self.beam_search(x=x, am_scores=am_scores, ...)
else:
    # === Greedy (贪心) ===
    yseq = am_scores.argmax(dim=-1)  # 每步取概率最大的 token
```

**对比**:

```
Beam Search:                              Greedy:
     ┌─── "你" (0.4) ─── "好" (0.3)          "你" (0.4) ─── "好" (0.3)
    /                                        ↙
start ──┤                          start ──→ "我" (0.3) ─── "是" (0.2)
    \   └── "我" (0.3) ─── "是" (0.2)        ...只选一条路
     └── "他" (0.2) ─── "是" (0.4)

输出: ["你","好"] (top-1)              输出: ["你","好"] (只有一条)
      + ["我","是"] (top-2)
      + ["他","是"] (top-3)
```

### 7.2 过滤特殊 Token

```python
# 去掉开头和结尾的 <sos> <eos>
yseq = [sos] + yseq + [eos]

# 去掉 blank_id (CTC 中用于表示"无输出"的空白符，通常为0)
token_int = filter(lambda x: x != sos and x != eos and x != blank_id, yseq)

# Token ID → 文字
token = tokenizer.ids2tokens(token_int)
```

## 8. 流式处理与缓存机制

### 8.1 为什么需要缓存？

CIF 的积分过程可能在一个 chunk 结束时还没完成，需要将状态缓存给下一个 chunk。

```
Chunk 0 输出:
┌────────────────────────────────────────────────────────────┐
│  ...  frames + alpha 累积到 0.8                              │
│  → 还差 0.2 就够输出下一个 token，但 chunk 结束了!           │
│  → 保存 integrate=0.8, frames到cache                         │
└────────────────────────────────────────────────────────────┘
                              ↓
Chunk 1 开始:
┌────────────────────────────────────────────────────────────┐
│  cache拼接 → 从 integrate=0.8 开始继续累积                   │
│  → 很快就能触发输出                                          │
│  → token不会丢失，也不会重复!                               │
└────────────────────────────────────────────────────────────┘
```

### 8.2 Cache 结构

```python
cache = {
    "prev_samples": torch,      # 原始音频样本缓存
    "frontend": {...},          # Fbank 提取器的缓存
    "encoder": {
        "feats": np,            # 编码器的输出特征
        "tail_chunk": bool
    },
    "cif_hidden": torch,        # CIF 预测器的隐藏状态
    "cif_alphas": torch,        # CIF 预测器的累积 alpha
}
```

### 8.3 Overlapping Chunk

```python
chunk_size = [0, 10, 5]
#             ↑  ↑  ↑
#             │  │  └─ 第二个数字=10，即chunk长度
#             │  └─ chunk间重叠的帧数 (lookback)
#             └─ 第一个数字=0，即左边不需要lookback
```

```
原始分块 (无重叠):              重叠分块 (overlap):
┌──────────┐                    ┌──────────┐
│ Chunk 0  │                    │ Chunk 0  │←←←←←┐
│ 0-600ms  │                    │ 0-600ms  │      │
└──────────┘                    └──────────┘      │
                                            overlap 300ms
                                             (5帧×60ms)
                                             ┌──────────┐
Chunk 1:                                    │ Chunk 1  │→→→→→┐
│ 600-1200ms│  ← 丢掉了"你"的右半部分          │ 300-900ms│      │
└──────────┘                                 └──────────┘      │
                                                             ↓
                                                      self-attention
                                                       能看到完整上下文
```

## 9. SpecAugment 数据增强

### 9.1 是什么？

SpecAugment 是在 **Fbank/梅尔频谱** 上随机"遮挡"一部分信息：

```
原始频谱:                    SpecAugment 后:
┌────────────────┐          ┌────────────────┐
│ ██████████████ │          │ ██░░░░░███████ │  ← 随机挖去几个频率段
│ ██████████████ │    →     │ █████████░░░░░ │
│ ██████████████ │          │ ████░░░░░█████ │
│ ██████████████ │          │ ██████████████ │
└────────────────┘          └────────────────┘
     时间 →                      时间 →
```

### 9.2 两种主要操作

| 操作 | 说明 | 图示 |
|------|------|------|
| **Frequency Mask** | 随机遮挡若干个频率段 | 竖条被抹掉 |
| **Time Mask** | 随机遮挡若干个时间段 | 横条被抹掉 |

### 9.3 为什么训练时要做这件事？

```
┌──────────────────────────────────────────────────────────┐
│                      训练阶段                            │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  真实录音环境多样:                                       │
│  ├── 安静房间                                           │
│  ├── 嘈杂咖啡厅                                         │
│  ├── 远场麦克风 (声音小、有混响)                         │
│  ├── 手机录音 (不同型号)                                │
│  └── 蓝牙电话 (有压缩和噪声)                            │
│                                                          │
│  如果只用干净数据训练:                                  │
│  → 模型只认识"完美"的语音                                │
│  → 遇到噪声就性能暴跌                                   │
│                                                          │
│  SpecAugment 模拟了各种"不完美"情况:                    │
│  → 让模型学会在部分信息缺失时仍能识别                    │
│  → 相当于"数据增强"                                      │
└──────────────────────────────────────────────────────────┘
```

### 9.4 代码示例

```python
if self.specaug is not None and self.training:  # ⚠️ 只在训练时启用
    speech, speech_lengths = self.specaug(speech, speech_lengths)
```

## 总结

```
音频 → 分块 → Fbank → 编码器 → CIF Predictor → 解码器 → 文字
         ↓        ↓         ↓          ↓           ↓
      600ms   80维     上下文     决定token    自回归
      划分    特征     表示       数量         生成
```

### 关键设计

1. **Chunk + Overlap**: 解决流式场景下边界信息丢失问题
2. **CIF Predictor**: 替代 CTC，将变长输入转换为变长输出
3. **Cache 机制**: 跨 chunk 的状态累积，保证 token 不丢失
4. **Tail Signal**: 最后一个 chunk 添加尾部信号，触发 CIF flush
5. **SpecAugment**: 训练时数据增强，提升模型鲁棒性
