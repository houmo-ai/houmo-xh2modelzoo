# MiniCPM-o examples

This directory contains local export, generation, and patch workflows for the
MiniCPM-o example flow.

## Code license

- The local example scripts in this directory are intended to be distributed
  under the repository's **Apache-2.0** licensing model.
- `patch/modeling_minicpmo.py` is an adapted file and carries its own
  provenance notice pointing to the upstream OpenBMB MiniCPM / MiniCPM-V
  project.

## Upstream components

- Upstream project: <https://github.com/OpenBMB/MiniCPM-V>
- Repository notice entry: see `THIRD_PARTY_NOTICES` under
  `MiniCPM-O-2.6 / MiniCPM Series`

## Redistribution rule

Code and assets are not the same compliance object.

- The Python scripts here can usually be reviewed as source-code artifacts.
- Files under `assets/` must be reviewed separately for provenance and
  redistribution rights.
- Before publishing this directory outside the repository, review
  `assets/PROVENANCE.md`.
