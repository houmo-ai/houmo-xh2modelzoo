## 迁移过程修复的问题

1. **Triton fp16/bf16 GEMM dtype 不匹配** — MoE grouped GEMM kernel 的 `out_dtype` 未指定
2. **TorchFX tracing 条件分支错误** — `_model.py` 中 `dtype == torch.bfloat16` 导致 FX trace 失败
3. **XH2a RMSNorm bf16 assertion** — quant 阶段需要用 fp16 而非 bf16
4. **ONNX bfloat16 → numpy 不支持** — 添加 bf16 dtype 映射和 uint16→fp16 常量转换
5. **transformers 5.2.0 breaking change** — `is_auto_gptq_available` 被移除
6. **gptqmodel TorchQuantLinear weight 属性冲突** — `_parameters.pop("weight")` 替代 `delattr`
7. **GPTQ 模型无 hf_quantizer** — 自动检测 quant_linear_cls
8. **ONNX model dict vs Config** — `qwen3_next_onnx_model.py` 支持 dict 类型的 config
