# PaddleOCR-VL

本目录包含 PaddleOCR-VL 视觉语言模型的xh2硬件部署实现。

## 特别事项

本项目使用以下第三方预训练模型和代码：

- 模型名称: PaddleOCR-VL
- 来源: https://github.com/PaddlePaddle/PaddleOCR
- 许可: Apache License 2.0 （https://www.apache.org/licenses/LICENSE-2.0）

预训练模型、配置文件和脚本在运行时下载，工程发布**不包含**该下载包。
同时，原有的推理与导出脚本已进行适配性修改，并包含在项目提交文件中。特此声明。

## 模型说明

PaddleOCR-VL 是 PaddlePaddle 团队开发的视觉语言OCR模型，支持：
- 场景文字检测与识别
- 版面分析
- 多语言OCR

本实现针对xh2硬件进行了优化：
- HMONNX导出流程
- 量化推理支持
- 批处理优化
